# Machine Learning 1

Учебные проекты и реализации по курсу «Машинное обучение — 1» ФКН НИУ ВШЭ.

В репозитории собраны эксперименты с классическими моделями и нейронными сетями, а также собственные реализации основных алгоритмов машинного обучения: линейной регрессии, методов оптимизации, решающих деревьев и градиентного бустинга.

## Ключевые результаты

- Реализованы с нуля оптимизаторы GD, SGD, SAG, Momentum и Adam.
- Реализовано решающее дерево для вещественных и категориальных признаков.
- Реализован градиентный бустинг для бинарной классификации.
- Обучена CNN для классификации городских звуков UrbanSound8K: средняя accuracy составила **80,76%** на 10-fold cross-validation.
- Реализована архитектура SPINN для решения трехмерного уравнения Гельмгольца.
- Проведен feature engineering для предсказания исходов матчей Dota 2.

### 4. Глубокое обучение

Работа состоит из двух независимых частей.

#### SPINN для трехмерного уравнения Гельмгольца

Реализована Separable Physics-Informed Neural Network:

- построена SPINN-архитектура;
- реализовано вычисление производных с помощью automatic differentiation;
- организовано обучение на коллокационных точках;
- исследовано влияние параметров архитектуры на качество решения.

#### CNN для классификации звуков

Обучена сверточная нейронная сеть для классификации записей из UrbanSound8K:

- построен пайплайн обработки аудио и вычисления спектрограмм;
- использовано разбиение по исходным fold датасета;
- проведен подбор архитектуры и параметров обучения;
- итоговая средняя accuracy на 10-fold cross-validation — **80,76%**.

- [Ноутбук](dl/homework-practice-04-dl.ipynb)

### 6. Градиентный бустинг

Реализован градиентный бустинг для бинарной классификации.

Поддерживаются:

- BCE и Focal Loss;
- early stopping;
- ordered target encoding категориальных признаков;
- квантизация признаков;
- GOSS-сэмплирование;
- L2-регуляризация;
- деревья, использующие градиенты и гессианы;
- расчет feature importance.

Проведено сравнение собственной реализации с библиотечными моделями и исследовано влияние параметров на ROC-AUC и калибровку вероятностей.
